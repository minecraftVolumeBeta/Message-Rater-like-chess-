this is a discord bot with A SINGLE COMMAND:

/evaluate

Use it by right clicking on any discord messaage (must be text)
Then select Apps -> Message Rater -> Evaluate.
The following are the possible values you can rate a message:

- Criminal
- Blunder
- Miss
- Mistake
- Inaccuracy
- Forced
- Good
- Excellent
- Best
- Book
- Great
- Brilliant
- Trilliant
- Trophy

The bot will generate a message and send it in chat.
